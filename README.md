# auto.incorrect 🔧🪄

auto.incorrect. turns your reading experience into a beautifully broken guessing game because nobody need accurate spelling anyway. 

## 🤔 What Is It?

Remember autocorrect? This is its evil twin.  

## ✨ Features

- Replaces normal words with *abnormal* ones.
- Makes reading unpredictable and maybe mildly annoying.
- Ideal for confusing your coworkers or making Wikipedia feel like experimental poetry.
- No settings, no control — just vibes.

## 🛠 Installation

1. Clone or [download this repo as a ZIP](#).
2. Go to `chrome://extensions/` in your browser.
3. Enable “Developer Mode” (top right).
4. Click **Load unpacked** and select the folder.
5. Refresh any tab and let the chaos begin.

## 🤯 Why?

Because language is fluid, reality is overrated, and you probably needed a little more mystery in your internet life.
